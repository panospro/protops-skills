# Empty states

- **Empty needs a next action.** "You have no projects" alone is a dead end; add the call-to-action ("+ Create new project") and a line explaining why it's empty. The empty state is often a user's first impression.
- **First-run onboarding checklist.** On initial-setup empty dashboards, show step-by-step tasks with completion progress.
- **Zero search results must move forward.** On a typo, offer "Did you mean [term]?" as a clickable corrected search — never a dead-end "no results".
- **Celebrate achieved-empty** — `suggest-only`. When empty is the goal (Inbox Zero, cleared task queue), celebratory visuals/streaks reward the user. Mixed usability/aesthetic claim: propose it, never auto-apply it.

**Audit checks:** list/collection renders with no explicit empty branch (blank screen when `items.length === 0`), empty branches that state emptiness without an action, search results pages with dead-end zero states.
